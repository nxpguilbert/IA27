Méthodologie

Comment lire ce site

Les analyses publiées ici sont produites par des outils d'IA générative. Elles sont utiles pour défricher un programme, mais ne remplacent ni un chiffrage officiel, ni une expertise humaine.

1. Le protocole

Consigne commune

Chaque outil reçoit la même consigne, en mode « recherche approfondie » lorsque l'outil le propose. Exemple de prompt :

Analyse le programme économique 2027 de [candidat/parti]. Pour chaque mesure majeure :
1. le chiffrage annoncé par le candidat ;
2. les évaluations indépendantes disponibles (fourchette, source) ;
3. les effets macroéconomiques attendus (croissance, emploi, déficit, dette) ;
4. les obstacles juridiques (Constitution, droit de l'UE) ;
5. les arguments favorables ET défavorables, avec sources.
Reste factuel et neutre, cite chaque chiffre.

Extraction

Les chiffres (montants annoncés, fourchettes indépendantes, projections) sont extraits manuellement du rapport et saisis dans un fichier de données par programme et par outil.

Neutralisation du ton

Les formulations militantes ou polémiques de l'IA sont reformulées. Le fond des conclusions est conservé et attribué à l'outil.

2. Lire les graphiques

Chiffrage du candidat (point = valeur unique, barre = fourchette)
Évaluation indépendante citée par l'IA (fourchette)
Valeur de référence (constat ou scénario tendanciel)

Survolez les graphiques pour afficher le détail. Chaque graphique propose une vue « tableau » pour l'accessibilité.

3. Les grilles de risque

Les niveaux de risque juridique ou économique sont ceux exprimés par l'IA. Ils sont représentés ainsi :

● Très élevé / bloquant ● Élevé ● Modéré ● Faible

4. Limites connues

  • Hallucinations : une IA peut inventer un chiffre ou une source. Les liens sont fournis pour vérification.
  • Biais de sources : la sélection des sources par l'IA peut favoriser certains think tanks.
  • Données datées : les programmes évoluent ; chaque fiche indique la date de l'analyse.
  • Une IA n'est pas un arbitre : les conclusions sont des avis argumentés, pas des faits établis.

5. Ajouter une analyse

  1. Créer assets/js/data-<parti>.js sur le modèle de data-lfi.js (recettes, dépenses, indicateurs clés, sources).
  2. Dupliquer programmes/lfi.html et adapter les textes.
  3. Dans index.html, renseigner l'URL et ajouter l'outil dans la liste done du programme.
